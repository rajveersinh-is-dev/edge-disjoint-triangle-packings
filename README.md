Edge-disjoint non-crossing triangle packings of planar point sets: a convex barrier and a reduction to subcubic trees

## Overview

`edge-disjoint-triangle-packings` provides algorithmic implementations and mathematical models for scientific and cryptographic applications, focusing on numerical stability, invariant verification, and performance.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/edge-disjoint-triangle-packings.git
cd edge-disjoint-triangle-packings
pip install -r requirements.txt
```

Run the automated verification suite:

```bash
pytest tests/
```
